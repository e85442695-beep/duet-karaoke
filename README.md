# Дует

[Відкрити караоке](https://e85442695-beep.github.io/duet-karaoke/)

Створи кімнату й надішли другу запрошення. Вибери пісню, увімкніть мікрофони й обоє натисніть «Готовий». Ведучий запускає спільний відлік. Синя та червона партії чергуються за куплетами.

## Як це працює

- GitHub Pages віддає статичні файли. Для локальної перевірки запусти `python -m http.server 8000` з кореня репозиторію та відкрий `http://localhost:8000/`. Для мікрофона потрібен localhost або HTTPS.
- Кімната живе, поки відкрита вкладка ведучого. Посилання на кімнату дає доступ одному гостю. Мікрофони передають звук через WebRTC. PeerJS Cloud потрібен для початкового встановлення зв’язку. TURN не налаштовано, тому деякі мережі можуть потребувати зміни підключення.
- Кожен браузер відтворює фонограму локально. Початок прив’язаний до оцінки різниці між годинниками браузерів. Затримка голосу залежить від мережі. Голоси не записуються.

## Пісні та фонограми

У каталозі короткі інструментальні версії народних пісень із мелодією-підказкою. Джерела мелодій і народних текстів

- «Несе Галя воду», збірник «Народна скарбівня», 2005, с. 45. [Відділ мистецтв Херсонської обласної бібліотеки](https://art.lib.kherson.ua/nese-galya-vodu.htm)
- «Ой у вишневому саду», традиційна мелодія за нотами з архіву хору «Гомін». У фонограмі використано власний супровід. [Ноти](https://torba.infoua.net/audio/homin/Oj-u-vyshnevomu-sadu_v7_NOTY.pdf)
- «Щедрик», народний текст і мелодія в обробці Миколи Леонтовича. [Партитура](https://uk.wikisource.org/wiki/Файл:Щедрик.pdf)

`tools/folk-scores.json` містить партії, слова і ритм. Після змін запусти `python tools/render-tracks.py` з NumPy та FFmpeg, щоб разом оновити фонограми й таймкоди.

PeerJS 1.5.5 та Inter розміщені в `vendor/` разом з їхніми ліцензіями.
